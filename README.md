# 🌐 Frontend del Sistema – Astro + TailwindCSS

Este proyecto corresponde al **frontend** de la aplicación, construido a partir de la plantilla **Astro Launch UI** y adaptado para las necesidades del sistema.  
El propósito principal de este frontend es interactuar con una **API REST**, desde donde obtiene y envía información mediante peticiones HTTP.

---

## 🚀 Tecnologías utilizadas

- **Astro** (arquitectura islands)
- **React** para componentes interactivos
- **TailwindCSS** para estilos
- **TypeScript**
- **REST API** para comunicación con el backend

---

## 📦 Instalación

Antes de comenzar, asegúrate de tener instalado:

- **Node.js** (versión 18 o superior)
- **npm**
